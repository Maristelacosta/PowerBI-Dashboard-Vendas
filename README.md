# Dashboard de Vendas \- Power BI

Dashboard desenvolvido para praticar conceitos básicos de Power BI.

- Faturamento Total
- Vendas por Produto
- Vendas por Região
- Filtros Interativos

## Ferramentas Utilizadas

- Power BI Desktop
- Microsoft Excel
- GitHub

## Arquivos

- Dashboard\_Vendas.pbix
- Planilha\_Exemplo\_PowerBI.xlsx

## Objetivo

Aprender modelagem de dados, criação de visuais e publicação de projetos em Power BI.
